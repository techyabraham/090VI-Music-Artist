## Release caveats

- The export is ready to host from `out/`; set `NEXT_PUBLIC_SITE_URL` to the production origin before building.
- System sans-serif fonts are used because the supplied folder has no approved brand-font files.
- The supplied ANIKE audio is about 21.1 seconds; owner confirmation and a longer approved clip are needed to meet the brief’s 45–60 second target.
- Release dates/catalogue, official links, all media rights, story/biography wording, and contact/provider configuration still need owner confirmation (see `CONTENT_REPORT.md`).
- No production domain, booking email, newsletter endpoint, shop backend, accounts, or event feed was supplied. These are represented honestly without fabricated functionality.
